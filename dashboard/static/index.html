    Ask about the line. The copilot only sees wafers up to the current line time.

    How it answers

    1. Line model names each wafer's defect pattern; confidence and review rules depend on whether the stream was scored by CNN or experimental YOLO.
    2. Alert rule fires when one tool produces the same pattern repeatedly (line-model predictions only).
    3. Copilot (LLM on AMD Token Factory) explains the likely cause, lots at risk and cost, citing its sources — answers are tied to the line time when you asked.
    4. Engineer decides: hold lots, open a ticket or dismiss.

    Root causes are triage possibilities from published sources, not diagnoses. Cost uses an adjustable wafer value.
